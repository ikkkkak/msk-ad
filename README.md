# 🌌 NovaDashboard

NovaDashboard is a modern, responsive UI dashboard template featuring a stylish sidebar, reusable components, and full support for dark and light modes. Perfect for admin panels, analytics apps, or any project that needs a clean and customizable UI.

## 🚀 Live Preview  
👉 [View Demo](https://nova-dashboard-pi.vercel.app)

## ✨ Features
- 🔥 Sleek & modern design  
- 🌗 Dark & light mode toggle  
- 🧩 Modular components (cards, charts, etc.)  
- 📱 Fully responsive for all screen sizes  
- ⚙️ Easy to customize and extend  
- 💡 Great starting point for any dashboard-based project

## 🧰 Getting Started
To get a local copy up and running:

```bash
git clone https://github.com/ExploitEngineer/NovaDashboard.git
cd NovaDashboard
```

Then open `index.html` in your browser, or use a local server like Live Server in VS Code for a better development experience.
